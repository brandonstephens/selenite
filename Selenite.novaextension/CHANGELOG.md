# Changelog

## 1.0.0

- Initial release.
- Ported Selenite, Selenite Dark, Selenite BG, Selenite Mono and
  Selenite Dark Mono from
  [tonsky/sublime-scheme-alabaster](https://github.com/tonsky/sublime-scheme-alabaster).
- Added Selenite Dark BG, a dark counterpart to Selenite BG that doesn't
  exist upstream, derived from Selenite Dark's palette using the same
  background-tint approach as the light BG variant.
