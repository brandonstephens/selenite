# Changelog

## 1.0.0

- Initial release.
- Ported Alabaster, Alabaster Dark, Alabaster BG, Alabaster Mono and
  Alabaster Dark Mono from
  [tonsky/sublime-scheme-alabaster](https://github.com/tonsky/sublime-scheme-alabaster).
- Added Alabaster Dark BG, a dark counterpart to Alabaster BG that doesn't
  exist upstream, derived from Alabaster Dark's palette using the same
  background-tint approach as the light BG variant.
