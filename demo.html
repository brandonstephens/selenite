Selenite

Selenite colors four things — strings, constants, comments, and the names you declare — and leaves everything else, including keywords like class, if, async, and new, in the default text color. Six variants apply that same idea differently: some use text color, some use a background tint, and the Mono pair drops color almost entirely.

Highlighting rules

Selenite ports Nikita Prokopov's Alabaster scheme for Sublime Text. Rather than color every token, it colors four categories and lets everything else — keywords, parameter names, variable names, plain member access — sit in the default text color. In the sample above, notice that class, if, async, await, new, and static, along with locals like response and userId, are the same color as the surrounding text. Only literals, comments, and the names being declared stand out.

Two details worth knowing: the ${…} interpolation inside a template literal is treated as part of the string, not as a constant — and an object or JSON key is colored identically to a string value, so key and value read as one continuous run of color rather than two different ones.

How each variant applies it

The four categories are the same across all six variants — what changes is whether a category is expressed as text color, a background tint, both, or left unstyled.

Only Selenite and Selenite Dark Mono dim brackets/operators at all — the other four variants leave punctuation in the default text color. In Selenite Mono specifically, strings, constants, and definitions all resolve to the same grey background tint, so those three categories are distinguished only by shape and position, not color.

A few upstream Alabaster details — nesting-depth bracket dimming, generic punctuation dimming, current-line/search-match/bracket-match highlighting, misspelling color, and diff markup (markup.inserted etc.) — have no matching hook in Nova's theme API and were dropped rather than approximated. Selenite Dark BG also isn't part of the original Alabaster scheme; it's this port's own extrapolation of the BG idea onto the Dark palette. Full details in the extension's README.
